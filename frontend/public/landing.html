What an investigation looks like

One item of evidence, taken through four stages. Each stage adds a layer; nothing is flattened into a single verdict. The example below is illustrative.

Evidence report Example

Supported

  • The same photograph appears in a report filed the day before the flood.
  • The publisher domain matches the organisation it claims to be.
  • Two independent outlets describe the same stretch of road.

Conflicts

  • The caption says Tuesday; the earliest version is dated Monday.
  • One account cites an unnamed official and no supporting document.

What remains unverified is listed as unverified — not folded into a verdict.

Beyond fake detection

A verdict is the least useful thing an investigation can produce. Here is what changes when the output is an evidence report instead.

Comparison of a typical fake-detector with the TrustLens evidence report
Capability A fake-detector TrustLens evidence report
Claims Partial Scores how the text is worded rather than testing the claim itself. Full Restates the claim, then tests it against the sources that report it.
Provenance None No record of where a file came from or how it changed. Full Traces earliest appearance, reposts and edits, and marks the gaps.
Link security None Links are copied past the analysis and never examined. Full Checks redirect chains, look-alike domains and known risk signals.
Conflicting evidence None Disagreement is averaged away into a single score. Full Places disagreeing sources together and shows what each rests on.
Explanation of findings Partial A verdict with little reasoning you can check or quote. Full Separates what is supported, what conflicts and what stays unverified.

No accuracy figures are claimed here — the output is reasoning you can read and check yourself.
